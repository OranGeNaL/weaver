## Context

`config.yaml` и `.env.example` — операторская документация. Сейчас комментарии вводят в заблуждение: `backup_hour` описан как локальное время, хотя контейнер обычно работает в UTC; настройки `MixesCfg` не видны оператору; часть Last.fm-переменных не читается кодом.

## Goals / Non-Goals

**Goals:**

- Сделать примеры конфигурации точным отражением текущих настроек.
- Убрать мёртвые ключи, которые не читаются.
- Документировать реальные настройки микса.

**Non-Goals:**

- Менять поведение `housekeeping` или переводить его на `ZoneInfo`.
- Менять значения по умолчанию `MixesCfg`.
- Добавлять новые настройки.

## Decisions

1. Оставить код `housekeeping` без изменений; исправить комментарий на «container time (UTC)».
2. В `config.example.yaml` добавить комментарии и значения по умолчанию для `MixesCfg`.
3. В `.env.example` удалить только неиспользуемые ключи Last.fm, сохранив `LASTFM_API_KEY`.
4. Если README ссылается на удалённые ключи, обновить и его.

## Risks / Trade-offs

- Операторы увидят больше настроек микса и могут захотеть их менять; значения остаются прежними.
- Если позже `backup_hour` переведут на локальную таймзону, комментарий придётся снова обновить.
