## ADDED Requirements

### Requirement: Загруженные треки добавляются в выбранный плейлист Hub

Hub SHALL читать `UploadCommitIn.playlist_id` как `playlist_uid` — `uid` плейлиста Hub — и MUST добавлять в него треки, импортированные через `POST /api/uploads/commit`. Плейлист MUST принадлежать текущему пользователю. Порядок элементов MUST соответствовать порядку `tracks` в запросе.

#### Scenario: Плейлист указан
- **WHEN** пользователь завершает загрузку с `playlist_id` и несколько треков успешно импортированы
- **THEN** Hub одним вызовом `playlists.add_tracks` добавляет `uid` этих треков в конец плейлиста
- **AND** порядок элементов совпадает с порядком `tracks` в запросе

#### Scenario: Плейлист не указан
- **WHEN** `playlist_id` отсутствует
- **THEN** Hub импортирует треки как раньше
- **AND** плейлисты не меняются

#### Scenario: Плейлист не найден или чужой
- **WHEN** `playlist_id` не соответствует плейлисту текущего пользователя
- **THEN** Hub возвращает `404` с русским `detail`
- **AND** не импортирует файлы и не создаёт альбом

#### Scenario: Ошибка импорта одного трека
- **WHEN** один из треков не удалось импортировать
- **THEN** остальные треки продолжают импортироваться
- **AND** в плейлист попадают только успешно импортированные треки в порядке запроса
