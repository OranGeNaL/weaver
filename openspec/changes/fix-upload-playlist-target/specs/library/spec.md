## ADDED Requirements

### Requirement: Загруженные треки добавляются в выбранный плейлист

Hub SHALL добавлять треки, импортированные через `POST /api/uploads/commit`, в плейлист `playlist_id` после появления `nd_song_id`. Порядок добавления MUST соответствовать порядку `tracks` в запросе.

#### Scenario: Плейлист указан
- **WHEN** пользователь завершает загрузку с `playlist_id` и несколько треков успешно импортированы
- **THEN** Hub создаёт отложенные добавления для этих треков
- **AND** после появления `nd_song_id` добавляет их в указанный плейлист в порядке запроса

#### Scenario: Плейлист не указан
- **WHEN** `playlist_id` отсутствует
- **THEN** Hub импортирует треки как раньше
- **AND** отложенные добавления не создаются

#### Scenario: Ошибка импорта
- **WHEN** один из треков не удалось импортировать
- **THEN** для него не создаётся отложенное добавление
- **AND** остальные треки продолжают обрабатываться

#### Scenario: Скан ещё не завершён
- **WHEN** `nd_song_id` ещё не появился
- **THEN** Hub оставляет отложенное добавление до следующего прохода
- **AND** не добавляет трек в плейлист раньше скана
