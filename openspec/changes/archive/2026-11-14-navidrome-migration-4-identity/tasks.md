- [x] 8.1 Лимитер входа считает по имени (`check_rate`), общий предохранитель сервера отделён, мёртвый `_attempts_in_window` удалён; тесты изоляции по имени и общего предела.
- [x] 8.2 `GET /api/auth/sessions` отдаёт только живые семьи и реальное время последнего использования (последняя ротация); тест на исчезновение отозванного устройства.
- [x] 8.3 Ротация refresh выполняется под `SELECT … FOR UPDATE`: одновременные запросы сериализуются, второй получает сохранённую пару; тест двумя сессиями.
- [x] 8.4 Неверные bootstrap-токены ограничены лимитером на `login_attempts`; сценарий спеки уточнён: повтор — `409`, лимитер — на неверные токены.
- [x] 8.5 `_optional_user` сохраняет `403` гейта `must_change_password` (OIDC link), самосравнение `state` в `oidc_link` убрано; тест `403`/`401`.
- [x] 8.6 `/api/auth/options` переживает нерасшифровываемый секрет провайдера: провайдер пропускается с предупреждением, экран входа работает.
- [x] 8.7 Сценарий «Начальный пароль» сужен до пароля из bootstrap-токена/CLI-сброса; env-пароль — осознанный выбор оператора.
- [x] 8.8 Downgrade миграции не требует `NOT NULL` для `nd_*`: откат не падает на БД с локальными учётками.
- [x] 8.9 Убран общий серверный предел лимитера (он же тотальный лок для любого имени): бюджет только по имени; ключ попытки ограничен длиной колонки, длинный логин не даёт `500`.
