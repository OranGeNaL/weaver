## MODIFIED Requirements

### Requirement: Прокси библиотеки Navidrome

До этапа 6 Hub SHALL сохранять `/api/nd/*` как deprecated-совместимый слой. Для пользователя с ND-кредами он MAY проксировать Navidrome; для пользователя без ND-кредов (созданного после этапа 4) он MUST отдавать ND-совместимую форму из Hub-каталога `/api/library/*`, а не `409`. Ошибки MUST преобразовываться в `404`/`403`/`502`.

#### Scenario: Главная библиотеки
- **WHEN** старая PWA вызывает `GET /api/nd/home`
- **THEN** Hub возвращает недавние, частые, новые и любимые альбомы и артистов
- **AND** для пользователя без ND-кредов данные берутся из Hub-каталога

#### Scenario: Плейлист другого пользователя
- **WHEN** запрошен чужой плейлист и доступа нет
- **THEN** Hub возвращает `403`

#### Scenario: Navidrome недоступен
- **WHEN** прокси к Navidrome завершается сетевой ошибкой
- **THEN** Hub возвращает `502` с русским сообщением

#### Scenario: Новый клиент
- **WHEN** клиент знает `hub_library_v1`
- **THEN** он использует `/api/library/*`
- **AND** не зависит от `/api/nd/*`
