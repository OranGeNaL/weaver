## Why

`ruff check` и `ruff format --check` входят в обязательный набор проверок Hub (правило `tasks` в
`openspec/config.yaml`), но предсуществующее состояние репозитория не проходит `ruff format --check`:
96 файлов `hub/` переформатируются. Ошибки `ruff check` (35) уже устранены точечно в
`navidrome-migration-1-postgres`, а форматный долг остаётся. Он маскирует смысловые diff'ы, мешает
приёмке change'ей и делает проверку 7.2 невыполнимой по вине базовой линии, а не изменения.

## What Changes

- Прогнать `ruff format` по `hub/` (app, tests, migrations) одним форматным коммитом.
- Закрепить версию `ruff` dev-зависимостью и зафиксировать порядок проверок: `ruff check` →
  `ruff format --check` → `pytest`.
- Добавить `.git-blame-ignore-revs`, чтобы форматный коммит не засорял историю строк.
- Отразить набор проверок в документации разработки.
- Не менять поведение, API, схему БД, конфигурацию и тестовые ожидания.

## Capabilities

 Нет: change помечен `skip_specs: true` (чистый тулинг, требований к системе не добавляет).

## Impact

- Код: `hub/**/*.py` — только пробелы, переносы и кавычки по правилам `ruff format`.
- Инструменты: `hub/pyproject.toml` (версия `ruff`), `.git-blame-ignore-revs`, документация проверок.
- API, БД, клиенты, фоновые задачи: без изменений.
- Проверка: `ruff check`, `ruff format --check`, `pytest` (текущая база — 1081 passed), `npm run typecheck`.
