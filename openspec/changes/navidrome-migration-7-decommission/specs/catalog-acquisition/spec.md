## MODIFIED Requirements

### Requirement: Унифицированный поиск

Hub SHALL объединять результаты поиска по собственной библиотеке и внешнему каталогу. Для внешнего каталога MUST использоваться Deezer; hitmoz MUST использоваться только для кириллических запросов и только если Deezer недоступен или не дал артистов/треков. Ответ MUST содержать признаки владения треками.

#### Scenario: Поиск по библиотеке и каталогу
- **WHEN** пользователь вызывает `GET /api/search?q=...`
- **THEN** Hub возвращает локальные треки, внешних артистов и альбомы, а также первые 25 внешних треков
- **AND** для треков указывает `owned`, `uid`/`library_track_id` и `downloading`
- **AND** ответ не содержит полей-алиасов внешнего медиасервера

#### Scenario: Продолжение списка треков
- **WHEN** клиент передаёт `offset` в `GET /api/search/tracks`
- **THEN** Hub возвращает следующую страницу внешних треков и `next_offset`
- **AND** `next_offset: null` означает конец списка

#### Scenario: Ошибка Deezer
- **WHEN** Deezer не отвечает при постраничном поиске
- **THEN** Hub возвращает `502`

#### Scenario: Fallback hitmoz
- **WHEN** Deezer недоступен, а запрос содержит кириллицу
- **THEN** Hub дополняет результаты hitmoz

#### Scenario: Латинский запрос без Deezer
- **WHEN** Deezer недоступен, а запрос не содержит кириллицы
- **THEN** Hub возвращает только локальные результаты и ошибки, без hitmoz-фолбэка
