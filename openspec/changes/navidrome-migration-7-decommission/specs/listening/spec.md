## MODIFIED Requirements

### Requirement: Подбор файла для прослушивания

Hub SHALL подбирать файл для `GET /api/listen?ref=...` тем же способом, что и загрузка: проверять библиотеку, каталог, порядок источников, длительность и версию. Результат MUST иметь вид `full`, `preview` или `library` и MUST кэшироваться. Библиотечный трек MUST адресоваться только `ref=lib:<uid>`; `nd:` и `lib:<int>` больше не принимаются.

#### Scenario: Трек уже в библиотеке
- **WHEN** запрошен `ref=lib:<uid>`, который есть в библиотеке
- **THEN** Hub возвращает `kind: "library"`
- **AND** `uid` заполнен
- **AND** `nd_song_id` отсутствует

#### Scenario: Полный файл найден
- **WHEN** источник отдаёт подходящий полный файл
- **THEN** Hub возвращает `kind: "full"`, провайдера, битрейт и `stream_url`

#### Scenario: Полного файла нет
- **WHEN** ни один источник не дал полный файл
- **THEN** Hub возвращает `kind: "preview"` с 30-секундным превью Deezer

#### Scenario: Ничего не найдено
- **WHEN** нет ни полного файла, ни превью
- **THEN** Hub возвращает `404` или `502` в зависимости от причины

#### Scenario: Старый ref
- **WHEN** запрошен `nd:<id>` или `lib:<int>`
- **THEN** Hub возвращает `404`
