## MODIFIED Requirements

### Requirement: «Моя волна»: запуск

Hub SHALL создавать волну без seed — от профиля вкуса, либо по треку, исполнителю, файлу или артисту Hub. Волна MUST выдавать до пяти треков за раз и MUST сохранять состояние сессии. Seed MUST использовать `song_uid`/`artist_uid`; иные идентификаторы трека/артиста MUST NOT приниматься.

#### Scenario: Личная волна
- **WHEN** пользователь вызывает `/api/wave/start` без seed
- **THEN** Hub строит волну от профиля вкуса
- **AND** при отсутствии истории и артистов возвращает `409`

#### Scenario: Волна по треку
- **WHEN** передан `seed.ref` или `seed.song_uid`
- **THEN** seed-трек становится первым треком волны

#### Scenario: Волна по артисту
- **WHEN** передан `seed.artist_ref` или `seed.artist_uid`
- **THEN** Hub строит волну вокруг артиста
- **AND** артист играет не чаще одного раза в три трека

#### Scenario: Волна по файлу
- **WHEN** передан `seed.ref` вида `file:<provider>:<id>`
- **THEN** Hub использует именно этот файл как первый трек
- **AND** не подменяет его библиотечной или каталожной версией

### Requirement: Умное перемешивание

Hub SHALL перемешивать собственные песни плейлиста или «Понравившихся» и вставлять рекомендации после каждой группы своих песен. Плейлист MUST NOT изменяться самим перемешиванием. Контекст плейлиста MUST использовать `playlist:<uid>`; `playlist:<int>` больше не принимается.

#### Scenario: Запуск smart shuffle
- **WHEN** клиент вызывает `/api/smart-shuffle/start` с `liked` или `playlist:<uid>`
- **THEN** Hub возвращает порядок собственных песен и первые рекомендации
- **AND** сохраняет сессию

#### Scenario: Следующая порция рекомендаций
- **WHEN** клиент вызывает `/api/smart-shuffle/{id}/next`
- **THEN** Hub учитывает прослушанные события и возвращает рекомендации для слотов впереди

#### Scenario: Скрыть рекомендацию
- **WHEN** пользователь скрывает трек в контексте
- **THEN** Hub сохраняет `smart_hidden`
- **AND** трек больше не рекомендуется в этом контексте

#### Scenario: Принять рекомендацию
- **WHEN** пользователь нажимает «+» для рекомендации
- **THEN** для плейлиста Hub добавляет песню или ставит её загрузку
- **AND** для «Понравившихся» только отмечает принятие, ♥ ставит клиент
