## ADDED Requirements

### Requirement: Планировщик ежедневного обслуживания переживает ошибки

Hub SHALL продолжать планировщик ежедневного обслуживания после неожиданного исключения из `run_daily`. Ошибка MUST логироваться и MUST NOT завершать фоновую задачу.

#### Scenario: Ошибка run_daily
- **WHEN** `run_daily` завершается неожиданным исключением
- **THEN** Hub логирует ошибку
- **AND** не пробрасывает её из планировщика
- **AND** следующая плановая попытка всё равно выполняется

#### Scenario: Отмена задачи
- **WHEN** планировщик отменяют при остановке приложения
- **THEN** `CancelledError` не превращается в обычную ошибку
- **AND** задача завершается как отменённая
